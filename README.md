# Dominic Soricelli — personal site

Live site: https://dsoricelli.github.io/mywebsite/

A hand-coded static site hosted on GitHub Pages.

## Structure

| File | Purpose |
|---|---|
| `index.html` | Home / about |
| `goals.html` | Goals |
| `Accomplishments.html` | Certifications and completed work |
| `Projects.html` | Network project before/after photos |
| `style.css` | Shared styles for every page (colors live at the top in `:root`) |
| `script.js` | Mobile menu, photo lightbox, footer year |
| `images/` | Web-sized images (resize photos to ~1400px wide before adding) |
